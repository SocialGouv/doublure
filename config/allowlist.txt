# Noms de FICHIERS dont l'extension coïncide avec un TLD. Le détecteur classe
# `infra.md` en URL (`.md` = Moldavie) : tout fichier Markdown nommé dans un
# prompt voit son extension muée en faux domaine, et l'agent ne retrouve plus
# le fichier que l'opérateur lui a désigné. Mesuré sur `tests/phase3_e2e.sh`.
#
# N'y figurent QUE des extensions dont l'usage comme nom d'hôte interne est
# invraisemblable. `.io`, `.ai`, `.dev`, `.app`, `.co`, `.sh` en sont
# volontairement ABSENTS : ce sont des domaines réellement utilisés.
#
# Le radical n'admet AUCUN point : un nom de fichier n'a qu'un seul label.
# L'autoriser (`[\w.-]+`) rendait public tout ce qui se termine par une de ces
# extensions — `srv-billing.acme.internal.conf`, `com.acme.Client.kt`,
# `10.0.0.5.log` — c'est-à-dire des hôtes internes et des IP, sortis en clair
# sans même une entrée de coffre pour le signaler.
#
# `.pl` (Pologne) et `.ml` (Mali) en sont ABSENTS pour la même raison, alors
# qu'ils désignent aussi du Perl et de l'OCaml : ce sont les deux ccTLD de la
# liste qui ont un vrai volume de domaines, et leur valeur comme extension de
# fichier est faible ici. L'arbitrage se rejuge extension par extension, pas
# en bloc.
#
# RÉSIDU ASSUMÉ, mesuré. La restriction du radical BORNE la fuite, elle ne la
# supprime pas : plusieurs de ces extensions restent des ccTLD (`.md`
# Moldavie, `.py` Paraguay, `.rs` Serbie, `.tf`), et un domaine EXTERNE à un
# seul label — `acme.md` — sort donc en clair. Le détecteur COMPTE désormais
# ces autorisations (`public_by_shape`) : le résidu n'est plus silencieux.
# Le détecteur ne permet pas de trancher : il rend les MÊMES types
# (HOSTNAME + URL) pour `acme.fr` dans « le serveur acme.fr » et pour
# `infra.fr` dans « le fichier infra.fr ». Et retirer ces extensions ferait
# muer `main.py`, `lib.rs` et `main.tf` en faux domaines — c'est ce qui a
# interrompu une session réelle, l'agent ne retrouvant plus le fichier qu'on
# lui désigne. Arbitrage : nom de fichier lisible > domaine externe d'un seul
# label. Les hôtes INTERNES, eux, sont multi-labels et restent couverts.
# --------------------------------------------------------------------------- #
